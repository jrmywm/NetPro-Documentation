# Getting Started with dpdk-frontend

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Clone the Repository

First, clone the repository from GitHub:

```sh
git clone https://github.com/Network-Laboratory-UI/dpdk-frontend.git
```

# Install Dependencies
Navigate to the project directory and install the necessary dependencies using npm:

```sh
cd dpdk-frontend
npm install
```

# Run the App
To start the app, use the following command:

```sh
npm run start
```

This will run the app in development mode. Open http://localhost:3005 view it in your browser.

The page will reload when you make changes. You may also see any lint errors in the console.

# Project Information
This project is built using React.js without any additional frameworks. The design is implemented using Tailwind CSS along with some additional libraries for icons.

- Public Folder: Contains all images used in the system.
- src Folder: Contains the main code.
  - components Folder: Contains small components that are called from other places.
  - pages Folder: Contains the views that are seen by the users, calling the components as needed.
